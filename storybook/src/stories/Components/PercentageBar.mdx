# Percentage Bar

The Percentage Bar component is used to display a percentage value with a visual representation.

It comes in two sizes. Use `medium` (7px, the default) for bars in narrow spaces such as tables, for a single wide bar, and for bars with markers. Use `small` (4px) for any other case, such as several bars stacked in a card.
